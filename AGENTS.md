# AI Stack Webapp

This is a webapp for sharing AI Stacks so that users can compare and choose the best set of tools for their needs.

## Development Process
* Web App is running on localhost:3000 - I am taking care of the dev servers running properly in my own terminal
* Never create or run convex migrations unless asked - we will re-seed from scratch every time the schema or seed changes
* Use playwright-cli to review frontend updates and reiterate if they don't work/look as expected
* Ensure `README.md` is up to date

## Tasks
* Before and during the requirements engineering process, use fast context to explore the current state
* Whenever you start with a task, ask the user questions to clarify all unknowns
* You are not allowed to make assumptions, ask the user questions instead
* Whenever you face challenges during development, also ask the user questions
* Use the question ask tool to verify with me if the task is complete or needs more work
* You can only declare a task as complete if you got my approval
