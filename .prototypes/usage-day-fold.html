One measured day: usage atoms beside workflow atoms, and the fold

The question. ADR-0010 puts the Actual Usage figures per UTC day into the same measuredDays row the workflow atoms live in. Does one row with two consent-gated blocks hold up when it is pushed through the cases: folding days into 30d / 7d / 24h, comparing with the previous period, a day where one model went unpriced, a stack that only ever synced an old 30-day snapshot, and an owner flipping consent after the days are stored? Every figure the page prints must come out of the fold, never out of a day.

Pure logic lives in the first <script> (liftable). The page is a shell. Storage is in memory: reload to wipe.
