# Security Policy

## Reporting a vulnerability

Please report suspected vulnerabilities through
[GitHub private vulnerability reporting](https://github.com/alp82/aistack/security/advisories/new).

Include:

- The affected component and version or commit.
- Steps to reproduce the problem.
- The potential impact.
- A proposed fix, if available.

Do not include credentials, personal data, or exploit details in public issues or
pull requests. Redact secrets and personal data from reproduction examples.

We will review the report and coordinate fixes and disclosure through the private
GitHub advisory.
