Thomas Ptacek argues that coding agents have made native interfaces affordable for personal tools, reducing the case for new terminal user interfaces. He still values command-line interfaces, but native frameworks handle scrolling, drag-and-drop, text selection, and accessibility more effectively. The advice targets developers with small utilities, especially those who can ask agents to generate SwiftUI applications. Simon Willison adds that he still uses two agent-built macOS monitoring applications every day.
