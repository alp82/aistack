OpenCode `v1.18.21` fixes responses that stopped early when a model returned an unrecognized finish reason. It routes Gemini requests in Vertex AI's `eu` and `us` multi-regions through REP endpoints. Desktop file search keeps existing results visible while a new query loads. The archive-session command now works in both desktop layouts.
