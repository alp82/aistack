headline: The Evolution of the Agent Harness
topic: Agent engineering
---

Dan McAteer argues that recent agent gains came from models and agent harnesses improving together. For AI engineers, a harness includes the tools, context, memory, permissions, and guardrails that let a model act. Harness-Bench found a 23.8-point performance spread across harnesses on 106 tasks with the same model, from 52.4 to 76.2. As models absorb more harness behavior, McAteer expects builders to focus on attention interfaces that govern interruptions, autonomous decisions, and human approvals.
