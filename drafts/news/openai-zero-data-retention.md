headline: Offering Zero Data Retention for frontier models
topic: Security and privacy
---

OpenAI reaffirmed Zero Data Retention for eligible API customers using frontier models. The policy targets organizations that need strict controls over data retained by API services. OpenAI also previewed Private Safety Processing, which it says supports advanced model safeguards without weakening data privacy.
