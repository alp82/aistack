OpenAI published Codex `0.150.0-alpha.7` for developers testing the latest command-line agent changes. The `/mcp` view now shows each server's live connection state and tool count, while `/mcp verbose` retains the full inventory. Strict Model Context Protocol auto-review now preserves denial, timeout, and cancellation results, including reviewer rationale. Unified execution also honors granular sandbox approvals for commands that request escalated access.
