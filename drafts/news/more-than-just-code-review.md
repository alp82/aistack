headline: More than just code review
topic: Agent engineering
---

Simon Willison argues that effective coding-agent use depends on clear instructions and confident verification of the resulting changes. The advice targets developers who delegate implementation work to agents but remain responsible for correctness. Line-by-line review can help, but Willison says it isn't always the best validation method. Teams need other checks that confirm agents applied changes correctly.
