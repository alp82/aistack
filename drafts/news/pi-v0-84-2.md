Pi v0.84.2 adds fullscreen transcript search with incremental highlighting and keyboard navigation for terminal coding-agent users. Users can configure startup tools globally or per project, choose fullscreen exit output, and select a per-run theme. Extension integrations gain template expansion, tokenless Cloudflare Workers AI Gateway routing, and preserved OpenAI Codex end-turn diagnostics. The release also fixes dropped streaming usage, delayed terminal startup, model refresh restarts, and several provider and fullscreen interaction bugs.
