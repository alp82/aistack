topic: Developer tools

Simon Willison released `llm` 0.33, updating the command-line model tool to OpenAI Python 3.x and replacing `httpx` with `httpx2`. Embedding commands and Python APIs now accept per-call API keys without changing shared model state. Users can repeat `-t` or `--template` to combine model settings from one template with a prompt from another. Responses API models gain `reasoning_summary` values of `auto`, `concise`, or `detailed`, including OpenAI-compatible endpoints.
