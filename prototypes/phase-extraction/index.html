// the question

Can the versioned phase rules alone classify real chat histories into scout, build, verify, and handoff, with a small unknown share and no LLM? Yes, but not the rules the spec described. Both specced sets failed on real history. The corrected set leaves 7% unknown across 464 sessions. The extractor ran on the owner machine and shipped aggregates only. This page renders those aggregates. It classifies nothing and calls no model.
