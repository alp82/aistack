The Session Phase Anatomy

The round-4 bar split session time into orient, build, verify, and gate. That split was hand-made. This demo makes it real. A versioned rule set reads recorded tool events and gives each event a phase. No rule match puts the event in the unknown bucket, which stays visible. The controls below change the rules and the time attribution. Every chart on this page re-derives live.

// DERIVATION NOTES
A subagent call owns only its capped gap here. In the real build the harness records each subagent in its own nested file, so its events classify on their own and the parent call stays thin. A session whose raw records are gone keeps the aggregate of the rule-set version that saw them. The demo marks one hand-made session this way to show the mixed-version coverage line.
