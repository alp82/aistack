PROTOTYPE · alp82/aistack#180 · news pipeline scrapers

Working scrapers for nine vendor news sources

All data on this page came from the live sites on 2026-08-19. Nothing is mocked. The first review round covered Anthropic, Claude and Gemini. This round adds OpenAI, Grok/xAI, pi, Hermes, DeepSeek and Kimi per operator request.
VERDICT: all nine scrapers work.

Each scraper ran three times against the live pages. The cold run seeds the baseline. The steady run reports zero new items. The detection run finds an entry that the test removed from the stored state, and extracts the real item from the live page. Two sources needed a workaround: OpenAI article pages are bot-blocked (the RSS archive fills the gap), and x.ai is fully bot-blocked (the docs site serves the API release notes).

Findings for the spec

  • The honest bot user agent beats a faked browser. Every source accepts aistack-news-collector-prototype. A faked full Chrome user agent breaks ai.google.dev with an endless redirect loop.
  • OpenAI needs no scraper. Cloudflare refuses every article-page fetch (403 on any user agent), but the RSS feed passes and holds the full archive of 1139 items with titles and dates. The phase-1 feed poller covers OpenAI completely. The sitemap-diff still works as a detector and enriches from the feed.
  • x.ai blocks all non-browser clients. Every path on x.ai answers 403. The docs site (docs.x.ai) serves plain HTML, so the API release notes are the scrapeable xAI surface. Consumer Grok news needs a browser or stays manual.
  • Language pinning is required for the Gemini changelog. Without ?hl=en and an Accept-Language: en header, Google serves a random language. One probe fetch came back machine-translated in Russian, which broke every content hash.
  • Script and style bodies must be stripped before hashing. The changelog page embeds a per-request analytics blob inside a script tag. Hashing the raw text marked all 106 sections as changed on every run.
  • The claude.com sitemap has no lastmod and lists five localized copies of each post. The filter keeps only default-locale URLs, and the item date must come from the JSON-LD datePublished on the article page.
  • The anthropic.com lastmod is an update time, not a publish time. The diff on URL presence is the newness signal, and the lastmod only labels the item date.
  • DeepSeek and Kimi article pages carry no machine-readable date. Their items are dated first-seen, which is accurate from the second collector run on.
  • The Nous sitemap does not separate posts from site pages. A new site page lands in the inbox as noise, and the curation gate (owner approves or discards) absorbs it.
  • pi belongs to the phase-1 feed poller. It has no blog. GitHub releases.atom is its news surface, shown here as a feed-diff. The feed holds only 10 entries, so the state must keep every id it has ever seen.
  • A cold run must not emit items. The nine baselines hold about 1500 historical entries (1085 OpenAI articles alone). The first run seeds the baseline silently, or the inbox floods.
  • The whole cycle is cheap. A steady run across all nine sources is 43 requests and about 17 seconds, dominated by the 35-child OpenAI sitemap walk. Every other source is one request.
