    The same issue, code-based

    The sync broadcast shipped this way. One issue costs these steps, every week:

    1. Open the repo and create src/emails/NewsIssue1Email.tsx with the week's items pasted in by hand.
    2. Copy each headline, link, date, and summary from the admin inbox into JSX.
    3. Register the issue in the BROADCASTS record in convex/email.ts.
    4. Open a pull request, review it, merge it, and wait for the deploy workflow.
    5. Trigger the send from the admin Broadcasts button, or over ssh.
    6. Mark alreadySent in code and merge again, so the button locks.
    7. Write the archive page under /news as a second manual artifact, or skip it.
    "news-issue-1": {
  subject: "AI Stack News #1",
  render: () => render(NewsIssue1Email({})),
  audience: "waitlist+members",
  category: "newsletter",
},
